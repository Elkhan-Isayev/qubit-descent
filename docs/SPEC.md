# ТЗ: qubit-descent — путешествие внутрь квантового компьютера

> Интерактивная WebGL-визуализация: непрерывный зум от криостата высотой ~3 м до одного атома фосфора в кремнии. На каждом уровне — что это за часть и **как её печатают** (литография). Научно точно, с источниками.

Автор: Elkhan Isayev. Предыдущий проект того же автора и стиля: [pangaea-drift](https://github.com/Elkhan-Isayev/pangaea-drift) — взять оттуда стек, структуру, CI, i18n, стиль README.

---

## 1. Цель и критерии успеха

- Эпичная, красивая визуализация для поста в LinkedIn (GIF/видео + живое демо на GitHub Pages).
- **Всё основано на реальных данных**: геометрия кубитов — из открытых инструментов проектирования чипов, цифры — из рецензируемых статей. У каждой подписи есть ссылка на источник.
- Позволяет корректно упомянуть и отметить: IBM Quantum, IQM, Google Quantum AI, Intel, imec, UNSW Sydney / Silicon Quantum Computing, QuTech / TU Delft.
- Работает на десктопе и телефоне, 60 fps на среднем ноутбуке.

## 2. Концепция: уровни зума

Скролл (или колесо / свайп / кнопки) плавно ведёт камеру вниз по масштабам. Переходы бесшовные (кроссфейд + масштабирование), а не отдельные слайды.

| # | Масштаб | Объект | Что показать | Литография / изготовление |
|---|---|---|---|---|
| 1 | ~3 м | Криостат растворения («люстра») | Ступени охлаждения: 300 K → ~50 K → ~4 K → ~1 K → ~100 мК → ~10 мК. Подсветка температуры цветом. Кабели, аттенюаторы | — |
| 2 | ~1 см | Чип в корпусе (sample holder) | Чип, wire bonds, коаксиальные разъёмы | Пластина → нарезка чипов |
| 3 | ~1 мм | Топология чипа | Кубиты, резонаторы считывания, линии управления, копланарные волноводы | Оптическая литография + травление ниобия/алюминия/тантала |
| 4 | ~300 мкм | Трансмон | Крестообразный (Xmon) или парный конденсатор, связь с резонатором | Электронно-лучевая литография |
| 5 | ~100 нм | Джозефсоновский переход | Al / AlOx / Al | **Ключевая анимация MVP:** напыление под двумя углами через подвесной мостик резиста (Dolan bridge) или Manhattan-схему, окисление между слоями, lift-off |
| 6 | ~2 нм | Туннельный барьер AlOx | Атомный масштаб, туннелирование куперовских пар (стилизованно) | Контролируемое окисление |
| 7 | 1 атом | Атом фосфора в кремнии (спиновый кубит) | Финал: «кубит — это буквально один атом» | Водородная литография иглой СТМ (Simmons, UNSW) |

### Финальный экран (v2): «Три способа напечатать кубит»

1. **Сверхпроводящий трансмон** (Google, IBM, IQM) — электронный луч + теневое напыление.
2. **Спиновые кубиты на промышленной фабрике** (Intel Tunnel Falls, imec) — 300-мм пластины, почти как обычный процессор. Мост к классической EUV-литографии (ASML).
3. **Атомная точность** (UNSW / Silicon Quantum Computing) — атомы ставятся по одному.

## 4. Стек и структура (как в pangaea-drift)

- **Vite 8**, **Three.js r186+**, ванильный JS (ES modules), без фреймворка.
- **Vitest + jsdom** для JS-тестов; **pytest** для Python-пайплайна.
- **Python-пайплайн данных** (`scripts/`): Qiskit Metal / KQCircuits / gdstk → GDS → полигоны по слоям → экструзия по толщинам слоёв → `public/data/*.bin` + `meta.json`. Отдельное venv, если зависимости тяжёлые.
- Node: `.nvmrc` (та же версия, что в pangaea-drift), `engines.node >= 22.12`.
- **GitHub Actions**: тесты → сборка → деплой на GitHub Pages; деплой только если тесты прошли. Node 24 actions.
- **i18n**: EN · AZ · DE · RU, переключение на лету, запоминание выбора, `?lang=`. Тексты уровней — в `src/i18n.js`.

```
qubit-descent/
├── index.html
├── src/
│   ├── main.js            # вход, UI, скролл → прогресс зума
│   ├── scene.js           # рендерер, камера, постобработка

│   ├── fabrication.js     # анимация напыления под двумя углами

└── .github/workflows/deploy.yml
```

## 5. Функциональные требования

### MVP (v1)
1. Уровни 1–7 в 3D с плавным логарифмическим зумом по скроллу; кнопки «следующий / предыдущий уровень» и индикатор масштаба (линейка: «3 m … 1 nm»).
2. На каждом уровне — карточка: название, 2–3 предложения, ключевые цифры, ссылка на источник.
3. **Одна анимация изготовления:** джозефсоновский переход (уровень 5) — резист, мостик, напыление Al под углом 1, окисление, напыление под углом 2, lift-off. Проигрывается по кнопке или при достижении уровня.
4. Геометрия уровней 3–4 — из реальных GDS (Qiskit Metal или KQCircuits), не нарисованная вручную.
5. Криостат (уровень 1): процедурная модель (цилиндры, пластины, коаксиалы) с цветовой индикацией температуры по ступеням.
6. i18n на 4 языка, адаптивная вёрстка, без горизонтального скролла на телефоне.
7. Раздел «Credits / Data sources» в UI и в README.

### v2
- Финальный экран «Три способа напечатать кубит».
- Анимации изготовления для уровней 3 (оптическая литография) и 7 (СТМ-литография).
- Режим «авто-тур» для записи видео/GIF.
- Опционально: живые калибровочные данные IBM (ошибки кубитов цветом) — только если доступны без утечки токенов на клиент.

## 6. Визуальный стиль

- Кинематографично, как pangaea-drift: тёмный фон, PBR-материалы (медь и золото криостата, сапфир/кремний подложки, алюминий), bloom, ACES tone mapping.
- Мягкий холодный свет на нижних ступенях криостата, «морозные» акценты.
- Атомный уровень — стилизованные сферы атомов кремния в решётке алмаза, атом P подсвечен.
- Типографика и HUD — в стиле pangaea-drift (крупное число масштаба вместо «million years ago»).

## 7. Тесты

- JS: логика зума (масштаб ↔ прогресс скролла, монотонность, границы), выбор уровня по масштабу, i18n (все ключи во всех языках), парсинг бинарных данных, компиляция шейдеров (как в pangaea-drift).
- Python: GDS → полигоны (количество слоёв, ограничивающие рамки в разумных микронах), целостность выходных файлов.
- CI блокирует деплой при падении тестов.
